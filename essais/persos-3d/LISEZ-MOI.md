# Essai : nouveaux persos 3D (abandonné, gardé pour mémoire)

Essais faits en novembre 2026 pour remplacer les persos en blocs par des persos stylisés
générés avec Meshy. Décision : on garde les blocs. Rien de ce dossier n'est utilisé par le jeu.

- `notes.md` : tout le déroulé, les réglages et les prix en crédits.
- `v2/` : les trois persos dans le style retenu (Awa, Koffi, Tantie Adjoua), `prompts.py` = la recette.
- `v3/` : changer de tenue, mélanger tête et tenue, accessoires, couleurs, enfant, gestes (`kit.js`).
- `v4/`, `v5/` : essais de visages animés (`face4.js`, `face5.js`).
- `v6/` : basket de rue, l'adaptateur des gestes du jeu vers un squelette (`poserig.js`).

Les images sont des JPEG réduits ; les vidéos et le modèle d'exemple de three.js (référence de
style) ne sont pas dans le dépôt. Les scripts envoient `Authorization: Bearer dummy` : la clé
est ajoutée par l'environnement, jamais écrite ici.
